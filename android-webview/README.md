# MyTube Android WebView - Ready Project

এই ফোল্ডারে Android Studio তে সরাসরি Open করার মতো ফাইল আছে।

## কিভাবে ব্যবহার করবেন:

1. Android Studio → Open → এই `android-webview` ফোল্ডার সিলেক্ট করুন
2. Gradle Sync হবে
3. `app/src/main/java/com/amin/mytube/MainActivity.kt` এ আপনার URL বসান
4. Run → APK Build

## Files:

- `app/src/main/AndroidManifest.xml` - Permission
- `app/src/main/res/layout/activity_main.xml` - WebView Layout
- `app/src/main/java/com/amin/mytube/MainActivity.kt` - WebView Code
- `build.gradle` - Dependencies
